COMPREHENSIVE ENGLISH PLACEMENT TEST WEBSITE
================================================

FASTEST WAY TO START ON WINDOWS
1. Extract the ZIP file.
2. Double-click START_TEST_WINDOWS.bat.
3. Keep the black command window open while taking the test.
4. The website opens at http://localhost:8765
5. Allow microphone access when the browser asks.

ALTERNATIVE START
- Double-click start_test.py if Python file associations are enabled.
- Or open a terminal in this folder and run:
  python start_test.py

IMPORTANT
- Use Chrome or Microsoft Edge.
- The microphone works best from http://localhost, not by double-clicking index.html.
- Select the correct input device in browser settings, such as “Microphone Array.”
- Answers and recordings stay on this device.
- Do not clear browser data during an attempt.
- At the end, click “Download all answers and recordings.”
- Upload the resulting ZIP to ChatGPT for grading.

TEST STRUCTURE
- Grammar: 30 minutes / 30 questions
- Use of English: 25 minutes / 25 questions
- Vocabulary & Phrasal Verbs: 20 minutes / 20 questions
- Reading: 35 minutes / 20 questions
- Listening: 25 minutes / 15 questions
- Writing: 45 minutes / 3 tasks
- Speaking: 30 minutes / 5 recordings

NAVIGATION
- Previous and Next move within the active section.
- Question-number buttons jump directly to a question.
- “Mark for review / not sure” flags a question.
- Submitted answers cannot be changed.
- Objective scores and correct answers appear after each submitted section.
- Completed-section results can be reopened from the results dashboard.
- A partial ZIP can be downloaded during any section break.
- Writing and speaking remain pending AI grading.
- The next section timer starts only after the candidate starts that section.

EXPORT PACKAGE
The final ZIP contains:
- responses.json
- grading_manifest.json
- response_summary.txt
- recordings/*.webm
- README.txt

This is an original diagnostic test. It is not an official CEFR, IELTS, Cambridge, or TOEFL certificate.


PAUSING AND PARTIAL RESULTS
- Every submitted objective section shows the score, selected answers, correct answers, and available explanations.
- Click “Pause and exit” after a section to save the attempt and close the browser.
- Reopen the site on the same device and resume later.
- Click “Download completed sections” to create a partial ZIP.
- Revealing answers before later sections can slightly influence a strict diagnostic result.
