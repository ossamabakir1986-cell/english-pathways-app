ENGLISH PATHWAYS — STUDENT EDITION 2.0

COURSE CONTENT
- 400 structured daily lessons
- Eight course stages from A1 to C2
- 10 units and 50 daily lessons in each stage
- Grammar, vocabulary, phrasal verbs, reading, listening, pronunciation, speaking, writing, quizzes and homework
- End-of-level exams
- Dictionary, Word Help and vocabulary notebook
- Voice recording and teacher submission

START
1. Extract the complete ZIP.
2. Double-click START_PLATFORM_WINDOWS.bat.
3. Keep the black command window open.
4. Use Chrome at http://localhost:8766
5. Allow microphone access and select Microphone Array.

FUTURE COURSE UPDATES
The teacher may send an official .json content pack.
1. Open Updates in the top menu.
2. Export a progress backup.
3. Select the update file.
4. Install it.
Existing progress remains saved.

The website does not download updates automatically. Do not install files from unknown sources.

SUBMISSIONS
The teacher submission endpoint is already configured. After an exam, use Submit to teacher and also download the ZIP backup.

DATA
Progress and recordings are stored on this browser and computer. Do not use Incognito mode or clear site data. Export backups regularly.

This platform provides educational and diagnostic assessment, not official certification.
