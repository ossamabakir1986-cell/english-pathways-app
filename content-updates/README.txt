CONTENT UPDATE PACKS

Version 2.0 already includes this expansion in the main course data.
The JSON file is supplied as an example and archival content pack.

From Version 2.0 onward, future content packs can be installed through:
Updates → Select content pack → Install.

Installed packs are stored in the browser and included in progress backups.
Existing lesson progress is preserved because stable lesson IDs are used.
