ENGLISH PATHWAYS v5.0.3 — ARABIC-FRIENDLY INTERFACE

WHAT THIS UPDATE DOES
- Adds an English / العربية interface switch for students.
- Translates student-facing menus, panels, profile/settings, help, contact, install prompts, practice hub, progress and common course controls.
- Keeps lesson content, exercises, placement testing and formal exams in English.
- Adds RTL treatment for Arabic panels without reversing English lesson content.
- Adds the language choice to Profile, More, onboarding and the top app bar.
- Stores the interface language in the student profile and local preference, so cloud sync can carry the preference with the unified account.
- Keeps the v5.0.2 Administration entry points.

FILES TO UPLOAD
Upload all files/folders in this package to the repository root and replace existing versions.
Do NOT replace config.js. This package does not contain config.js.

AFTER DEPLOYMENT
Open English Pathways, use the العربية button in the top bar, or choose العربية in Profile / More.
Use English to switch back.

CACHE
The service-worker cache version is v5.0.3 and includes ui-language.js.
