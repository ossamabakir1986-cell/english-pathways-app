ENGLISH PATHWAYS MOBILE APP PWA v1.0

Built from English Pathways Student Edition v3.0.

Mobile improvements:
- Installable Android/iPhone Home Screen PWA
- Bottom tabs: Home, Learn, Dictionary, Progress, More
- Large touch controls and safe-area support
- Mobile lesson action bar
- Full-screen mobile dictionary and Word Help popup
- Offline caching after first successful online load
- Mobile microphone recording with browser-appropriate audio format
- Exam submission sends the exam speaking recording plus exam data
- Backup exports retain all saved course recordings
- Progress and More dashboards
- App install guidance built into the UI

Teacher submission endpoint is already configured.

This package must be hosted on HTTPS for students. Local preview files are included only for the owner/testing.

Course data: v3.0, 400 lessons, A1–C2.
